# Classi

منصة تجمع الطلاب وأولياء الأمور مع المعلمين الخصوصيين ومعلمي المدارس والمعاهد.

- **الواجهة:** Next.js، بالعربية من اليمين لليسار، وتُثبَّت على الهاتف كتطبيق.
- **قاعدة البيانات والدخول:** Supabase.
- **النشر:** Vercel.

## ما يعمل في هذه المرحلة

- البحث والفلترة حسب النوع والمادة والمرحلة والمكان والبلد.
- صفحات المعلمين والمعاهد والعروض.
- الحجز لكل نوع:
  - درس خصوصي: يختار الطالب موعداً من أوقات المعلم الفارغة، ويصل الطلب للمعلم ليقبله أو يرفضه.
  - مجموعة تقوية: يحجز مقعداً في لقاء محدد.
  - دورة معهد: تسجيل في الدورة كاملة.
  - محتوى مسجّل: شراء مرة واحدة.
- حساب ولي الأمر مع الأبناء، وجدول يجمع حصص الجميع، وإلغاء الحجز حتى 24 ساعة قبل الحصة.
- لوحة المعلم:
  - إنشاء ملف المعلم.
  - طلبات الحجز مع القبول والرفض.
  - نشر عروض جديدة، والحقول تتغير حسب النوع.
  - رؤية دوراته في المعاهد.
- لوحة المعهد:
  - القاعات والمعلمون.
  - إنشاء دورة مع جدولة لقاءاتها تلقائياً.
  - تعديل موعد أو قاعة لقاء واحد أو كل اللقاءات بعده، مع فحص التعارض.
  - تسجيل الحضور.
- **إبلاغ الجميع عند تغيير الموعد:** يصل إشعار للمعلم ولكل من حجز، ويُسجَّل التغيير في سجلّ المعهد.
- الحماية: كل مستخدم يرى بياناته فقط (Row Level Security)، ولا يستطيع أحد أن يوثّق نفسه أو يغيّر تقييمه.

## التشغيل لأول مرة

### 1. Supabase

1. افتح مشروعك ثم **SQL Editor**.
2. انسخ محتوى `supabase/migrations/20261024000000_init.sql` والصقه، ثم اضغط **Run**.
3. انسخ محتوى `supabase/seed.sql` والصقه، ثم اضغط **Run**. هذا يضيف البيانات التجريبية: 16 معلماً و4 معاهد.
4. اضبط عناوين الموقع:
   - من **Authentication** ثم **URL Configuration**، اجعل **Site URL** رابط موقعك على Vercel.
   - أضف تحت **Redirect URLs** الرابط نفسه مع `/auth/callback`.
5. خذ المفتاحين من **Project Settings** ثم **API**:
   - `Project URL`
   - `anon public`

### 2. Vercel

1. من **Add New Project** اختر مستودع `classi` من GitHub.
2. أضف تحت **Environment Variables**:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. اضغط **Deploy**.

### 3. ربط حساب تجريبي بمعلم أو معهد

المعلمون والمعاهد التجريبيون ليس لهم حسابات. لتجربة لوحة المعهد بالبيانات الجاهزة:

1. أنشئ حساباً جديداً في التطبيق.
2. نفّذ في **SQL Editor** (غيّر البريد إلى بريدك):

```sql
update institutes set owner_id = (select id from auth.users where email = 'you@example.com')
where name = 'مركز النخبة للتعليم';
```

وللمعلم:

```sql
update teachers set user_id = (select id from auth.users where email = 'you@example.com')
where name = 'سامر مصاروة';
```

### 4. توثيق معلم أو معهد جديد

```sql
update teachers set verify = 'verified' where name = 'اسم المعلم';
update institutes set verify = 'verified' where name = 'اسم المعهد';
```

## اختبار قاعدة البيانات محلياً

`supabase/tests/run.sh` ينشئ قاعدة نظيفة، ويطبّق الجداول والبيانات، ثم يجرّب سيناريو كاملاً:

1. حجز.
2. منع الحجز المزدوج.
3. قبول المعلم.
4. منع تعارض القاعات.
5. تغيير المواعيد وإبلاغ الجميع.

## المرحلة القادمة

- الدخول برقم الهاتف.
- رسائل واتساب.
- الدفع عبر Bit وبطاقات الائتمان.
- الدردشة.
- التقييمات.
- لوحة مدير لتوثيق المعلمين.
- تعديل الأوقات المتاحة للمعلم.

## تحديث: الصور ولوحة الإدارة

- نفّذ `supabase/migrations/20261024010000_photos_admin.sql` في SQL Editor.
- لجعل حسابك مديراً (مرة واحدة، غيّر البريد):

```sql
update profiles set roles = array_append(roles, 'admin')
where id = (select id from auth.users where email = 'you@example.com');
```

ثم تظهر "لوحة الإدارة" في صفحة حسابي لتوثيق المعلمين والمعاهد.
